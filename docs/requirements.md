# 电子信息文献研究 Agent 第一版需求

## 1. 项目定位

面向电子信息、通信、信号处理、计算机和人工智能领域的多智能体文献研究系统。系统根据中文研究问题生成中英文检索策略，检索并核验学术论文，最终生成带可追溯引用的中文文献综述。

## 2. 目标用户与场景

- 电子信息相关专业学生：课程论文、毕业设计选题和研究综述。
- 科研人员：快速了解研究方向、技术路线和代表性论文。
- 工程人员：对比学术方案、工程局限和发展趋势。

## 3. 输入与默认值

输入为自然语言研究问题，可包含主题、时间范围、方向、论文数量和输出语言。未指定时使用以下默认值：

- 时间范围：不限。
- 学术检索语言：优先英文，可使用中文补充背景。
- 单次检索数量：10 篇。
- 最终候选论文上限：20 篇。
- 输出语言：跟随用户语言。

## 4. P0 核心功能

1. Supervisor 将复杂研究问题拆分为独立子任务。
2. Researcher 使用 arXiv 和 Semantic Scholar 检索论文，使用 Crossref 补全和核验元数据。
3. 论文统一为 `Paper` 结构，保留标题、作者、摘要、年份、DOI、arXiv ID、URL、来源和出版载体。
4. 按 DOI、arXiv ID、规范化标题依次去重，并合并不同来源的元数据。
5. 使用确定性规则计算相关性、来源质量、学术影响力和综合分数；相关性权重高于引用量。
6. 只允许具有有效 DOI、arXiv ID 或 Semantic Scholar Paper ID 且带规范 URL 的论文进入引用白名单。
7. 最终报告只能从白名单引用学术论文；未知 DOI/arXiv 链接会被标记并记录。
8. LangSmith 可以追踪检索、规范化和报告生成节点。

## 5. 论文数据结构

```json
{
  "title": "论文标题",
  "authors": ["作者 1", "作者 2"],
  "abstract": "论文摘要",
  "published_year": 2025,
  "doi": "10.xxxx/xxxx",
  "arxiv_id": "2501.12345",
  "url": "论文原始页面",
  "source": "arxiv+crossref",
  "venue": "期刊或会议",
  "research_direction": "研究方向",
  "relevance_score": 0.9,
  "quality_score": 0.95,
  "verification_status": "verified"
}
```

标题、URL 和来源必须存在。无法确认的年份、DOI、arXiv ID 或出版载体保持为空，禁止模型补写。

## 6. 去重和合并规则

1. DOI 相同判定为同一论文。
2. 无 DOI 时，arXiv ID 相同判定为同一论文。
3. 标识不同但规范化标题相同时合并记录。
4. 优先保留有 DOI、元数据更完整、来源已验证的记录。
5. arXiv 与 Crossref 指向同一论文时，合并 DOI、arXiv ID、作者和出版载体。

## 7. 来源与引用规则

来源优先级为：出版社或会议官网、Crossref/DOI、arXiv、Semantic Scholar、研究机构官网、其他网页。博客和聚合网站只用于背景信息，不作为论文元数据来源。

Semantic Scholar 用于补充引用量、影响力引用量和开放获取信息。引用指标只能作为影响力信号，不能证明论文结论正确，也不能替代主题相关性判断。API 失败或限流时，系统保留已有 arXiv/Crossref 记录并继续生成报告。

- 论文元数据只能来自工具结果。
- 学术引用必须有 DOI 或 arXiv ID 和有效 URL。
- 不得生成检索结果中不存在的论文、DOI 或 URL。
- 未获得足够论文时，报告说明实际数量和检索限制。

## 8. 最终报告格式

第一版输出 Markdown，建议包含：

1. 研究背景。
2. 检索范围与方法。
3. 主要技术路线。
4. 代表性论文比较表。
5. 局限性与工程难点。
6. 未来研究方向。
7. 结论。
8. 参考文献或 Sources。

## 9. 验收标准

- 学术问题至少调用一次 `search_arxiv`。
- 返回的论文记录可从工具输出中机器解析。
- 重复 DOI、arXiv ID 或标题不重复进入白名单。
- 时间范围配置能过滤已知年份不符合要求的论文。
- Crossref 失败时保留原始 arXiv 记录并继续执行。
- 无稳定标识的记录进入拒绝列表。
- 最终报告中的 DOI/arXiv 链接来自白名单。
- 工具、去重、评分和引用验证均有无需真实网络的单元测试。

## 10. 第一版不实现

- 用户 PDF 上传与解析。
- 向量数据库和本地知识库 RAG。
- 付费论文下载或付费墙绕过。
- 论文引用量和作者影响力的完整统计。
- Web 前端、用户账户和生产级权限管理。
- 模型训练或微调。

## 11. 后续版本

- 接入更多电子信息领域数据库。
- 增加 PDF 分块、Embedding 和向量检索。
- 增加报告导出、缓存、成本统计和 Docker 部署。
